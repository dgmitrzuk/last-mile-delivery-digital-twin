# Last-Mile Delivery Digital Twin

## Master Thesis Project

**Sequential and Competitive Facility Location Problem in Last-Mile Delivery**

Warsaw School of Economics (SGH)

**Author:** Dawid Gmitrzuk  
**Supervisor:** Daniel Kaszyński, PhD

---

## Overview

This project develops a digital twin framework for analyzing and optimizing
last-mile delivery networks under competitive and sequential facility location
decisions.

The research combines:

- geospatial analytics,
- facility location optimization,
- agent-based simulation,
- demand modeling,
- network analysis,
- operational decision-making.

The objective is to simulate how logistics operators make location decisions
over time and how these decisions influence customer accessibility,
competition, and network performance.
